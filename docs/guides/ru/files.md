Desktop Subsystem for Android™ (DSA) позволяет открывать файлы Android в проводнике, открывать
доступ к вашим папкам Windows для приложений Android и отправлять файл в приложение Android. На
этой странице описан DSA в Windows.

## Открытие файлов Android в проводнике

Воспользуйтесь любым из способов. Каждый из них запускает Android, если он не запущен.

- **Android** в области навигации проводника, сразу под **Linux** от WSL.
- **Android files** на странице **Advanced** (дополнительно) в DSA Settings.
- `dsa files open`. `dsa files` сообщает, где находится хранилище, не открывая его.

Вы видите общее хранилище Android: файлы, сохранённые приложениями Android, например фотографии
и загрузки. Копировать файлы туда и оттуда можно, как в любой папке. Проводник обращается к
хранилищу через клиент WebDAV Windows. Если хранилище не отвечает, DSA показывает ошибку с
причиной.

## Доступ к папкам Windows для приложений Android

Ваши папки «Документы», «Загрузки», «Изображения», «Музыка», «Видео» и «Рабочий стол»
отображаются в общем хранилище Android в `Host`, например `Host/Pictures`. Приложения Android
могут открывать и сохранять там файлы. Сначала приложению нужно разрешение Android на доступ к
хранилищу, а Windows позволяет ему только то, что может ваша собственная учётная запись.

Общий доступ включён по умолчанию. Чтобы изменить это, откройте страницу **Advanced** в DSA
Settings:

- Выключите **Share Windows folders with Android**, чтобы не открывать доступ ни к одной папке.
- В разделе **Shared folders** снимите отметку с папки, чтобы закрыть к ней доступ. Она сразу
  исчезает из Android.

Из командной строки:

```
dsa settings set shared-folders Documents,Pictures   # только эти; также all или none
dsa settings set file-sharing off                     # не открывать ни одной папки
```

Ранние версии использовали папку `Windows` вместо `Host`. Android удаляет старую папку, когда
она становится пустой, поэтому сохранённые там файлы остаются.

## Отправка файла в приложение Android

- **Перетаскивание.** Перетащите файл из проводника на окно приложения. Файл попадёт в это
  приложение. APK вместо этого попадает в APK Installer. Папки не отправляются.
- **Контекстное меню.** Щёлкните файл правой кнопкой мыши и выберите **Open in an Android app**
  или **Share with an Android app**. В Windows 11 эти пункты находятся в разделе **Показать
  дополнительные параметры**. Затем Android спрашивает, какое приложение примет файл.
- **Командная строка.** `dsa open <file>` и `dsa share <file>`.

Так отправляются файлы размером до 64 МиБ. Файл большего размера отклоняется до начала отправки.
Чтобы передать приложению файл большего размера, поместите его в общую папку.

## Получение файла из Android

- Сохраните его в Android в `Host/<folder>`. После этого он окажется в этой папке на вашем ПК.
- Или откройте **Android** в проводнике и скопируйте файл оттуда.
