Эти руководства объясняют, как установить Desktop Subsystem for Android™ (DSA) и пользоваться
им, а также что делать, если что-то пошло не так.

Они описывают текущую версию в разработке. В последнем выпуске может не быть части описанного
здесь, а его примечания к выпуску перечисляют, что в него входит. Всё незавершённое помечено
как таковое.

| Руководство | Что с его помощью можно сделать |
|---|---|
| [Начало работы](getting-started.md) | Установить DSA в Windows и узнать о состоянии в Linux и macOS |
| [Приложения и окна](apps.md) | Открывать приложения, работать с их окнами и полноэкранным режимом, уведомлениями, виджетами, фоновыми приложениями, Google Play, Widevine, приложениями ARM и правами root |
| [Установка APK](install-apks.md) | Устанавливать приложения из файлов APK и узнавать, почему установка отклонена |
| [Файлы](files.md) | Открывать файлы Android в проводнике и отправлять файлы в приложения Android |
| [Версии Android](android-versions.md) | Узнавать и менять, какая версия Android запущена |
| [Параметры](settings.md) | Находить каждый параметр в DSA Settings и его имя в `dsa settings` |
| [Память](memory.md) | Понять Doze, заморозку и то, как память возвращается вашему ПК |
| [Режим разработчика и adb](developer-mode.md) | Подключить adb к Android |
| [Устранение неполадок и журналы](troubleshooting.md) | Найти причину проблемы, читать журнал Android и отправить сообщение о проблеме |
| [Удаление](uninstall.md) | Удалить DSA и узнать, что сохраняется |

Впервые знакомитесь с проектом? Начните с [вводной страницы](../intro/index.html).
