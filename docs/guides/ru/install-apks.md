# Установка APK

Desktop Subsystem for Android™ (DSA) не поставляет магазин приложений. Приложения
устанавливаются из файлов APK с помощью APK Installer или команды `dsa`. На этой странице описан
DSA в Windows.

## Установка с помощью APK Installer

1. Дважды щёлкните файл `.apk` в проводнике. Он откроется в **APK Installer** (установщик APK).
2. Проверьте, что это за APK. Окно показывает это, не запуская Android:
   - имя, значок, пакет и версию приложения;
   - издателя, взятого из сертификата подписи, потому что APK не указывает издателя;
   - источник: хост, с которого был загружен файл, или его папку;
   - в разделе **Capabilities** первые запрашиваемые разрешения. **More** показывает их все,
     версии Android, для которых создано приложение, его размер, типы процессоров и SHA-256 его
     сертификата.

   Если в APK есть код только для другого типа процессора, окно предупреждает вас.
3. Выберите **Install**. Если приложение уже установлено, кнопка называется **Update** или
   **Install again**. Если Android не запущен, сначала запускается он.
4. Если отмечено **Launch when ready** (по умолчанию), приложение открывается сразу после
   установки, а установщик закрывается. Иначе выберите **Launch** или откройте приложение позже
   из меню «Пуск».

Пока Android запущен, окно также сообщает, является ли файл новой установкой, обновлением, той
же версией или тем, что Android отклонит: более старой версией или тем же приложением,
подписанным другим ключом.

Файлы APK можно также перетащить на APK Installer, на DSA Settings или на окно приложения.
Каждый APK открывается в собственном окне установщика.

## Установка из командной строки

```
dsa apk-info app.apk            # что это за APK; читает файл, не запуская Android
dsa install app.apk             # установить его; запускает Android, если он не запущен
dsa install app.apk --progress  # также выводить каждый шаг
```

Если Android отклоняет APK, `dsa install` завершается с кодом 1, а его сообщение начинается с
`not installed (<reason>):`.

## Почему установка отклонена

| Причина | Значение | Что делать |
|---|---|---|
| `incompatible` | Приложению нужен другой тип процессора, более новая версия Android или функция, которой нет на этом устройстве | См. [Приложения только для ARM](apps.md#приложения-только-для-arm) или [Версии Android](android-versions.md) |
| `conflicting-signature` | Приложение уже установлено и подписано другим ключом | Сначала удалите установленное приложение |
| `downgrade` | Установлена более новая версия приложения | Сначала удалите установленное приложение |
| `invalid-apk` | Файл не является подписанным APK, который может прочитать Android | Загрузите APK заново |
| `insufficient-storage` | В Android нет места для приложения | Освободите место в Android |
| `blocked` | Политика этого Android не разрешает приложение | |
| `other` | Всё остальное; далее следует собственное сообщение Android | |

Размер APK может достигать 2 ГиБ. Установки выполняются по одной: вторая ждёт завершения первой.

## Удаление приложения

Воспользуйтесь любым из способов:

- **Параметры** Windows > **Приложения** > **Установленные приложения**.
- Страница **Apps** в DSA Settings: **Uninstall** рядом с приложением.
- `dsa apps uninstall <package>`.

Приложения, входящие в состав Android, удалить нельзя.
