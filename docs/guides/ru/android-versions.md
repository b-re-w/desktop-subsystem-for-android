# Версии Android

Desktop Subsystem for Android™ (DSA) поддерживает две новейшие основные версии Android: сейчас
это Android 16 и Android 17. По умолчанию запускается самая новая. Некоторые приложения работают
только на одной из них, поэтому версию можно выбрать.

## Какая версия запущена

Откройте страницу **Updates** (обновления) в DSA Settings. В разделе **Android** показаны
версия, её сборка, уровень исправлений безопасности, версия, которой она следует, и состояние
обновления с ходом загрузки. **Check now** просит службу сразу проверить наличие обновления.
Или выполните:

```
dsa android version   # запущенная версия и версии, которые можно выбрать
```

## Смена версии

Все пользователи ПК работают с одной и той же версией Android, поэтому менять её может только
администратор.

1. Откройте страницу **Updates** в DSA Settings.
2. В разделе **Version to use** выберите версию или **Always the newest**.
3. Выберите **Change** и подтвердите запрос администратора.

Выбранная версия загружается и используется со следующего запуска Android. Из терминала
администратора:

```
dsa android use 16
dsa android use latest
```

### Переход на более старую версию стирает данные

Android не может читать данные, записанные более новой версией. Поэтому переход на более старую
основную версию стирает данные Android всех пользователей ПК: установленные ими приложения, их
аккаунты и все данные приложений. Параметры DSA сохраняются. Это действие нельзя отменить.

DSA Settings просит подтвердить это кнопкой **Erase data and change**. В командной строке
добавьте `--erase-data`:

```
dsa android use 16 --erase-data
```

Переход на более новую версию сохраняет ваши приложения и данные.

## Обновления

- Выбранная версия продолжает получать обновления безопасности.
- Когда версия перестаёт поддерживаться, DSA переходит на следующую и сохраняет ваши приложения.
- DSA никогда сам не переходит на более старую основную версию.
- Перед использованием каждый образ сверяется с подписанным списком. Образ, который не
  загружается, заменяется предыдущим.

Администратор может выключить обновления образа параметром **Update the Android image
automatically** на странице **Updates** в DSA Settings или командой
`dsa settings set image-updates off`.
