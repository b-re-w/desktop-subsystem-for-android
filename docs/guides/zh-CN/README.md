# DSA 用户指南

[English](../README.md) · [한국어](../ko/README.md) · [日本語](../ja/README.md) · **简体中文** · [繁體中文](../zh-TW/README.md) · [Español](../es/README.md) · [Français](../fr/README.md) · [Deutsch](../de/README.md) · [Português (Brasil)](../pt-BR/README.md) · [Русский](../ru/README.md) · [Italiano](../it/README.md) · [Tiếng Việt](../vi/README.md) · [Bahasa Indonesia](../id/README.md) · [Türkçe](../tr/README.md)

这些指南介绍如何安装和使用 Desktop Subsystem for Android™（DSA），
以及出现问题时该怎么办。

指南描述的是当前的开发版本。
最新发布的版本可能缺少这里介绍的部分内容；
它包含哪些内容，请查看其发行说明。
尚未完成的内容都会注明。

| 指南 | 可以用它做什么 |
|---|---|
| [入门](getting-started.md) | 在 Windows 上安装 DSA，并了解 Linux 和 macOS 上的进展 |
| [应用与窗口](apps.md) | 打开应用，使用其窗口和全屏，通知、小部件、后台应用、Google Play、Widevine、ARM 应用和 root 访问权限 |
| [安装 APK](install-apks.md) | 从 APK 文件安装应用，并了解安装被拒绝的原因 |
| [文件](files.md) | 在文件资源管理器中打开 Android 的文件，并把文件发送给 Android 应用 |
| [Android 版本](android-versions.md) | 查看和更改运行的 Android 版本 |
| [设置](settings.md) | 在 DSA Settings 中找到每项设置及其 `dsa settings` 名称 |
| [内存](memory.md) | 了解 Doze、冻结，以及内存如何归还给您的电脑 |
| [开发者模式与 adb](developer-mode.md) | 将 adb 连接到 Android |
| [故障排除与日志](troubleshooting.md) | 诊断问题、读取 Android 的日志并提交报告 |
| [卸载](uninstall.md) | 删除 DSA，并了解哪些内容会保留 |

初次接触本项目？请从[介绍页面](../intro/index.html)开始。
