# DSA ユーザーガイド

[English](../README.md) · [한국어](../ko/README.md) · **日本語** · [简体中文](../zh-CN/README.md) · [繁體中文](../zh-TW/README.md) · [Español](../es/README.md) · [Français](../fr/README.md) · [Deutsch](../de/README.md) · [Português (Brasil)](../pt-BR/README.md) · [Русский](../ru/README.md) · [Italiano](../it/README.md) · [Tiếng Việt](../vi/README.md) · [Bahasa Indonesia](../id/README.md) · [Türkçe](../tr/README.md)

このガイドでは、Desktop Subsystem for Android™ (DSA) のインストール方法と使い方、そして問題が起きたときの対処方法を説明します。

ガイドは現在の開発版について説明しています。
最新のリリースには、ここで説明している内容の一部がないことがあります。
リリースに何が含まれているかは、そのリリース ノートに書かれています。
完成していないものには、その旨を記しています。

| ガイド | できること |
|---|---|
| [はじめに](getting-started.md) | Windows に DSA をインストールし、Linux と macOS の状況を確認する |
| [アプリとウィンドウ](apps.md) | アプリを開き、そのウィンドウと全画面表示、通知、ウィジェット、バックグラウンド アプリ、Google Play、Widevine、ARM アプリ、root 権限を扱う |
| [APK のインストール](install-apks.md) | APK ファイルからアプリをインストールし、インストールが拒否された理由を調べる |
| [ファイル](files.md) | Android のファイルをエクスプローラーで開き、Android アプリにファイルを送る |
| [Android のバージョン](android-versions.md) | 動いている Android のバージョンを確認し、変更する |
| [設定](settings.md) | DSA Settings の各設定と、その `dsa settings` での名前を調べる |
| [メモリ](memory.md) | Doze、フリーズ、メモリが PC に返される仕組みを理解する |
| [開発者モードと adb](developer-mode.md) | adb を Android に接続する |
| [トラブルシューティングとログ](troubleshooting.md) | 問題を診断し、Android のログを読み、報告を送る |
| [アンインストール](uninstall.md) | DSA を削除し、何が残るかを確認する |

初めての方は、[紹介ページ](../intro/index.html) から始めてください。
