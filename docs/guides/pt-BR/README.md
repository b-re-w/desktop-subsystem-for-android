# Guias do usuário do DSA

[English](../README.md) · [한국어](../ko/README.md) · [日本語](../ja/README.md) · [简体中文](../zh-CN/README.md) · [繁體中文](../zh-TW/README.md) · [Español](../es/README.md) · [Français](../fr/README.md) · [Deutsch](../de/README.md) · **Português (Brasil)** · [Русский](../ru/README.md) · [Italiano](../it/README.md) · [Tiếng Việt](../vi/README.md) · [Bahasa Indonesia](../id/README.md) · [Türkçe](../tr/README.md)

Estes guias explicam como instalar e usar o Desktop Subsystem for Android™ (DSA) e o que fazer
quando algo dá errado.

Eles descrevem a versão de desenvolvimento atual. A versão lançada mais recente pode não ter
parte do que está descrito aqui; as notas da versão listam o que ela contém. Tudo o que não
está pronto diz isso.

| Guia | O que você pode fazer com ele |
|---|---|
| [Primeiros passos](getting-started.md) | Instalar o DSA no Windows e ver o status no Linux e no macOS |
| [Apps e janelas](apps.md) | Abrir apps, trabalhar com as janelas e a tela cheia, notificações, widgets, apps em segundo plano, Google Play, Widevine, apps ARM e acesso root |
| [Instalar APKs](install-apks.md) | Instalar apps a partir de arquivos APK e descobrir por que uma instalação foi recusada |
| [Arquivos](files.md) | Abrir os arquivos do Android no Explorador de Arquivos e enviar arquivos para apps Android |
| [Versões do Android](android-versions.md) | Ver e mudar a versão do Android que roda |
| [Configurações](settings.md) | Encontrar cada configuração nas DSA Settings e o nome dela no `dsa settings` |
| [Memória](memory.md) | Entender o Doze, o congelamento e como a memória volta para o seu PC |
| [Modo de desenvolvedor e adb](developer-mode.md) | Conectar o adb ao Android |
| [Solução de problemas e logs](troubleshooting.md) | Diagnosticar um problema, ler o log do Android e enviar um relato |
| [Desinstalação](uninstall.md) | Remover o DSA e ver o que é mantido |
