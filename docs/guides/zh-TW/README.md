# DSA 使用指南

[English](../README.md) · [한국어](../ko/README.md) · [日本語](../ja/README.md) · [简体中文](../zh-CN/README.md) · **繁體中文** · [Español](../es/README.md) · [Français](../fr/README.md) · [Deutsch](../de/README.md) · [Português (Brasil)](../pt-BR/README.md) · [Русский](../ru/README.md) · [Italiano](../it/README.md) · [Tiếng Việt](../vi/README.md) · [Bahasa Indonesia](../id/README.md) · [Türkçe](../tr/README.md)

這些指南說明如何安裝與使用 Desktop Subsystem for Android™（DSA），以及發生問題時該怎麼做。

指南描述的是目前的開發版本。
最新發行的版本可能缺少這裡描述的部分內容；其版本資訊會列出它包含的項目。
尚未完成的部分都會註明。

| 指南 | 可以做什麼 |
|---|---|
| [開始使用](getting-started.md) | 在 Windows 上安裝 DSA，並查看 Linux 與 macOS 的狀態 |
| [應用程式與視窗](apps.md) | 開啟應用程式，操作其視窗與全螢幕、通知、小工具、背景應用程式、Google Play、Widevine、ARM 應用程式與 root 存取權 |
| [安裝 APK](install-apks.md) | 從 APK 檔案安裝應用程式，並了解安裝遭拒的原因 |
| [檔案](files.md) | 在檔案總管中開啟 Android 的檔案，並將檔案傳送給 Android 應用程式 |
| [Android 版本](android-versions.md) | 查看並變更執行的 Android 版本 |
| [設定](settings.md) | 在 DSA Settings 中找到每項設定及其 `dsa settings` 名稱 |
| [記憶體](memory.md) | 了解 Doze、凍結，以及記憶體如何歸還給您的電腦 |
| [開發人員模式與 adb](developer-mode.md) | 將 adb 連線到 Android |
| [疑難排解與記錄](troubleshooting.md) | 診斷問題、閱讀 Android 的記錄，以及提交回報 |
| [解除安裝](uninstall.md) | 移除 DSA，並了解哪些內容會保留 |
