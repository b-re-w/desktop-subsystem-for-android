Diese Anleitungen erklären, wie Sie Desktop Subsystem for Android™ (DSA) installieren und
verwenden und was Sie tun können, wenn etwas nicht funktioniert.

Sie beschreiben die aktuelle Entwicklungsversion. Dem neuesten Release kann ein Teil des hier
Beschriebenen fehlen; seine Versionshinweise führen auf, was es enthält. Was nicht fertig ist,
ist als solches gekennzeichnet.

| Anleitung | Was Sie damit tun können |
|---|---|
| [Erste Schritte](getting-started.md) | DSA unter Windows installieren und den Stand unter Linux und macOS sehen |
| [Apps und Fenster](apps.md) | Apps öffnen, mit ihren Fenstern und dem Vollbild arbeiten, Benachrichtigungen, Widgets, Hintergrund-Apps, Google Play, Widevine, ARM-Apps und Root-Zugriff |
| [APKs installieren](install-apks.md) | Apps aus APK-Dateien installieren und herausfinden, warum eine Installation abgelehnt wurde |
| [Dateien](files.md) | Die Dateien von Android im Explorer öffnen und Dateien an Android-Apps senden |
| [Android-Versionen](android-versions.md) | Sehen und ändern, welche Android-Version läuft |
| [Einstellungen](settings.md) | Jede Einstellung in DSA Settings und ihren Namen in `dsa settings` finden |
| [Speicher](memory.md) | Doze, das Einfrieren und die Rückgabe von Speicher an Ihren PC verstehen |
| [Entwicklermodus und adb](developer-mode.md) | adb mit Android verbinden |
| [Fehlerbehebung und Protokolle](troubleshooting.md) | Ein Problem diagnostizieren, das Protokoll von Android lesen und einen Bericht einreichen |
| [Deinstallation](uninstall.md) | DSA entfernen und sehen, was erhalten bleibt |

Neu im Projekt? Beginnen Sie mit der [Einführungsseite](../intro/index.html).
