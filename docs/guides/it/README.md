# Guide per l'utente di DSA

Queste guide spiegano come installare e usare Desktop Subsystem for Android™ (DSA), e che cosa
fare quando qualcosa non funziona.

Descrivono l'attuale versione di sviluppo. L'ultima versione rilasciata può non avere tutto
ciò che è descritto qui; le sue note di rilascio elencano che cosa contiene. Ciò che non è
finito lo dice esplicitamente.

| Guida | Che cosa permette di fare |
|---|---|
| [Per iniziare](getting-started.md) | Installare DSA su Windows e conoscere lo stato su Linux e macOS |
| [App e finestre](apps.md) | Aprire le app, lavorare con le loro finestre e con lo schermo intero, notifiche, widget, app in background, Google Play, Widevine, app ARM e accesso root |
| [Installare APK](install-apks.md) | Installare app da file APK e scoprire perché un'installazione è stata rifiutata |
| [File](files.md) | Aprire i file di Android in Esplora file e inviare file alle app Android |
| [Versioni di Android](android-versions.md) | Vedere e cambiare la versione di Android in esecuzione |
| [Impostazioni](settings.md) | Trovare ogni impostazione in DSA Settings e il suo nome in `dsa settings` |
| [Memoria](memory.md) | Capire Doze, il congelamento e come la memoria torna al PC |
| [Modalità sviluppatore e adb](developer-mode.md) | Collegare adb ad Android |
| [Risoluzione dei problemi e log](troubleshooting.md) | Diagnosticare un problema, leggere il log di Android e inviare una segnalazione |
| [Disinstallazione](uninstall.md) | Rimuovere DSA e sapere che cosa viene conservato |

È nuovo del progetto? Inizi dalla [pagina di introduzione](../intro/index.html).
