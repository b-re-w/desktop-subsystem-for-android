# Guías del usuario de DSA

[English](../README.md) · [한국어](../ko/README.md) · [日本語](../ja/README.md) · [简体中文](../zh-CN/README.md) · [繁體中文](../zh-TW/README.md) · **Español** · [Français](../fr/README.md) · [Deutsch](../de/README.md) · [Português (Brasil)](../pt-BR/README.md) · [Русский](../ru/README.md) · [Italiano](../it/README.md) · [Tiếng Việt](../vi/README.md) · [Bahasa Indonesia](../id/README.md) · [Türkçe](../tr/README.md)

Estas guías explican cómo instalar y usar Desktop Subsystem for Android™ (DSA), y qué hacer
cuando algo falla.

Describen la versión de desarrollo actual. Puede que a la última versión publicada le falte
algo de lo que se describe aquí; sus notas de la versión indican lo que contiene. Lo que no
está terminado lo indica.

| Guía | Qué puede hacer con ella |
|---|---|
| [Primeros pasos](getting-started.md) | Instalar DSA en Windows y ver el estado en Linux y macOS |
| [Aplicaciones y ventanas](apps.md) | Abrir aplicaciones, trabajar con sus ventanas y la pantalla completa, las notificaciones, los widgets, las aplicaciones en segundo plano, Google Play, Widevine, las aplicaciones ARM y el acceso root |
| [Instalar APK](install-apks.md) | Instalar aplicaciones desde archivos APK y averiguar por qué se rechazó una instalación |
| [Archivos](files.md) | Abrir los archivos de Android en el Explorador de archivos y enviar archivos a aplicaciones de Android |
| [Versiones de Android](android-versions.md) | Ver y cambiar la versión de Android que se ejecuta |
| [Configuración](settings.md) | Encontrar cada opción en DSA Settings y su nombre en `dsa settings` |
| [Memoria](memory.md) | Entender Doze, la congelación y cómo vuelve la memoria a su equipo |
| [Modo de desarrollador y adb](developer-mode.md) | Conectar adb a Android |
| [Solución de problemas y registros](troubleshooting.md) | Diagnosticar un problema, leer el registro de Android y enviar un informe |
| [Desinstalar](uninstall.md) | Quitar DSA y ver qué se conserva |

¿Es nuevo en el proyecto? Empiece por la [página de introducción](../intro/index.html).
