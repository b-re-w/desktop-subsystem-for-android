Panduan ini menjelaskan cara menginstal dan menggunakan Desktop Subsystem for Android™ (DSA),
serta apa yang harus dilakukan saat terjadi masalah.

Panduan ini menjelaskan versi pengembangan saat ini. Rilis terbaru mungkin belum memiliki
sebagian dari yang dijelaskan di sini; catatan rilisnya mencantumkan isinya. Apa pun yang
belum selesai dinyatakan demikian.

| Panduan | Yang dapat Anda lakukan dengannya |
|---|---|
| [Memulai](getting-started.md) | Menginstal DSA di Windows, dan melihat status di Linux dan macOS |
| [Aplikasi dan jendela](apps.md) | Membuka aplikasi, bekerja dengan jendela dan layar penuhnya, pemberitahuan, widget, aplikasi latar belakang, Google Play, Widevine, aplikasi ARM, dan akses root |
| [Menginstal APK](install-apks.md) | Menginstal aplikasi dari file APK, dan mengetahui mengapa instalasi ditolak |
| [File](files.md) | Membuka file Android di File Explorer, dan mengirim file ke aplikasi Android |
| [Versi Android](android-versions.md) | Melihat dan mengubah versi Android yang berjalan |
| [Pengaturan](settings.md) | Menemukan setiap pengaturan di DSA Settings beserta namanya di `dsa settings` |
| [Memori](memory.md) | Memahami Doze, pembekuan, dan bagaimana memori kembali ke PC Anda |
| [Mode pengembang dan adb](developer-mode.md) | Menghubungkan adb ke Android |
| [Pemecahan masalah dan log](troubleshooting.md) | Mendiagnosis masalah, membaca log Android, dan mengirim laporan |
| [Pencopotan](uninstall.md) | Menghapus DSA, dan melihat apa yang dipertahankan |

Baru mengenal proyek ini? Mulailah dari [halaman pengantar](../intro/index.html).
